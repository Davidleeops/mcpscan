Codex Apply Command

After approval, Codex can save the approved message to a temporary file and run the post-click handoff. It applies the approved links, verifies Stripe format, checks Stripe QA evidence when provided, verifies DNS, runs launch checks, and refreshes status.

npm run launch:post-click-verify -- --file /path/to/approved-return-packet.txt --qa-file /path/to/stripe-checkout-qa-evidence.json --apply true
