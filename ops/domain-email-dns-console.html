After DNS Saves

  1. Run the approved launch-link command after Stripe links exist so landing/CNAME becomes the domain you bought.
  2. In GitHub Pages settings, set the custom domain to the chosen domain.
  3. Wait for DNS checks, then enable or confirm HTTPS enforcement.
  4. Verify the live homepage, secure intake page, and matching audit mailbox for the chosen domain.

Do Not Skip

Do not publish outbound emails from the new audit@ mailbox until MX, SPF, DKIM, and DMARC pass. If DKIM is not configured, deliverability will be weaker and security buyers may notice.
