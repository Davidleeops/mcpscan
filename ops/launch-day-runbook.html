npm run launch:post-click-verify -- --file /path/to/approved-return-packet.txt --qa-file /path/to/stripe-checkout-qa-evidence.json --apply true
npm run launch:publish-pages-fallback -- --wait true
npm run launch:verify -- --domain {{chosen_domain}}
npm run launch:status:live

Stop Conditions

  • No outbound until MX, SPF, DKIM, and DMARC pass.
  • No public Stripe links until checkout QA evidence passes.
  • No external messages without exact recipient and content approval in the same turn.
  • No customer secrets, private configs, customer data, or final private reports in the public repo.
