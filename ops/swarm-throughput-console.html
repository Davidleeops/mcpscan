Swarm Throughput Console

Use this after launch gates are live to keep market, outbound, reply, payment, and delivery work split into agent lanes with clear approval gates.

Operating model Launch day First 10 Paid handoff Delivery

Throughput Rule

Agents prepare and verify. The founder approves account clicks, exact public claims, exact outbound content, paid handoffs, and commit or push after live verification.

Agent Lanes

Market Pulse

Refresh buyer pain and claim boundaries before campaigns.

npm run market:verify

Domain And Mailbox

Keep DNS, mailbox records, and public contact gates aligned.

npm run launch:verify-dns

Stripe And Checkout

Create link packets, QA evidence, and return values.

npm run launch:verify-stripe-qa

Public Launch

Apply approved public values, publish fallback, and verify live.

npm run launch:post-click-verify

Outbound Prep

Prepare first-10 packets and stage approved drafts outside the public repo.

npm run outbound:send-gates

Reply To Close

Turn replies into approved responses, scope, and payment routes.

npm run outbound:open-reply-close

Paid Delivery

Create the private workspace and work order after payment evidence.

npm run delivery:verify

Quality And Safety

Run the consolidated proof and stop unsafe claims or actions.

npm run launch:full-proof

Daily Loop

  1. Run launch status.
  2. Clear founder-click gates if any remain.
  3. Approve one outbound batch or one reply action.
  4. After payment, create a private delivery handoff.
  5. Run delivery verification before accepting customer materials.
npm run launch:status
npm run launch:day
npm run launch:open-first-revenue
npm run delivery:open-handoff

Do Not Cross

  • No outbound before domain, mailbox authentication, Stripe links, and security contact are live.
  • No customer secrets or customer configs in the public repo.
  • No named vulnerability claims without authorized evidence.
  • No automatic sending or charging from agent lanes.
