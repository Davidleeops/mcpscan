Static Launch Bundle

Use this fallback when GitHub Pages is stale or blocked. It builds a clean upload folder from the current landing site.

Approval QueueLaunch CockpitBundle Guide

When To Use It

Use this when the public GitHub Pages site is not updating because Actions or Pages is blocked. This does not replace the normal GitHub Pages path. It gives you a fast static-host fallback.

Build Command

npm run landing:sample-report
npm run launch:bundle

Upload Folder

Upload every file inside this folder to the static host:

dist/mcpscan-static-launch/

Netlify

Create a manual deploy or static site, then upload the folder contents. No build command is required for this fallback.

Vercel

Create a static project from the folder contents or drag the generated folder into a manual deployment flow.

Other Hosts

Any host that serves static HTML can work. Set index.html as the entry page and preserve the file names.

Do Not Upload Yet If

  • Stripe links are placeholders but the page is meant to collect live paid orders.
  • The domain and mailbox have not been approved in the return packet.
  • The folder contains anything outside the public landing site.

After Upload

npm run launch:verify -- --domain {{chosen_domain}}
