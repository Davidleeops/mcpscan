Recipient Finder

Find the exact public recipient before first-wave outreach. This console opens searches and builds an approval packet. It does not send messages.

Open packetCandidate CSVApproval builderAccount copy

No-Send Rule

No outreach can be sent until the exact recipient and exact final content are approved in the same turn. Do not use unverified scraped personal data.

Recipient Standard

Prefer public founders, CTOs, product security leads, platform leads, customer trust leads, or developer experience owners who can plausibly own MCP rollout and security evidence.

Readiness Check

Run this before asking for approval. Warnings mean exact recipients are still missing. Failures mean the candidate data is malformed.

npm run outbound:verify
