Outbound Approval Queue

Generate the first-wave draft queue, choose one account, then build an exact recipient approval packet. This page prepares the path only. It does not send anything.

Open queue First 10 Approval builder Find recipient

Send Boundary

No email, LinkedIn message, form submission, Slack message, or customer-facing contact happens from this queue. Exact recipient and exact final content still need same-turn approval.

Refresh Queue

Run this after market refresh or pipeline edits. It rebuilds `sales/outreach-approval-queue.md` from the first-wave pipeline.

npm run outbound:queue

Approval Flow

  1. Open the generated queue.
  2. Pick one account and one route.
  3. Find the exact public recipient or approved contact route.
  4. Use the approval builder for exact final content.
  5. Stage outside the public repo only after approval.
