Verification Console

Use this after each launch gate. It checks required local artifacts and public URLs, then reports warnings for founder-gated items that are not done yet.

Launch Status

Use this to see the current gates and next founder clicks.

npm run launch:status
npm run launch:status:live

Current GitHub Pages Verification

npm run launch:verify

Post-Click Return Review

Open the founder return packet, Stripe QA page, status tracker, verification console, final click path, and supporting docs before applying live values.

npm run launch:open-return-review

Custom Domain Verification

Run after DNS and GitHub Pages custom domain are configured.

npm run launch:verify -- --domain CHOSEN_DOMAIN

DNS and Mail Verification

Run after the domain, GitHub Pages records, MX, SPF, DKIM, and DMARC are saved. Add the DKIM selector shown by Spacemail when available.

npm run launch:verify-dns -- --domain CHOSEN_DOMAIN --update-status --dkim-selector DKIM_SELECTOR

Stripe Payment Link Verification

Run after the three Stripe Payment Links are created and before applying them to the public landing page. Add update status after the founder return packet has created the local tracker.

npm run launch:verify-stripe -- --quick QUICK_PAYMENT_LINK --launch LAUNCH_PAYMENT_LINK --enterprise ENTERPRISE_PAYMENT_LINK --update-status

Market Source Verification

Run before outbound batches or public market claims.

npm run market:verify

Public Launch Review

Open the public launch approval packet, market brief, public trust checklist, claim safety guide, public pages, and post staging command before publishing anywhere.

npm run launch:open-public-review

Outbound Readiness Verification

Run before requesting founder approval for exact recipients.

npm run outbound:verify

First-Send Gate Review

Open the founder tracker, first-10 approval packet, approval builder, send-gate command, send logging docs, and revenue snapshot path before any outreach is sent.

npm run outbound:open-send-gates

Reply-To-Close Review

Open the inbound reply templates, staging rules, customer comms, checkout QA surface, post-payment path, and send logging docs before replying to a prospect.

npm run outbound:open-reply-close

Writing Rule Check

Run before release to confirm the banned punctuation rule is clean.

npm run writing:check

GitHub Actions Billing Lock

If GitHub shows red checks because jobs never start, open the billing unblock console.

Billing unblock console

Strict Mode

Use strict mode only after domain, email, Stripe links, and custom URLs are fully approved. It exits non-zero on warnings.

npm run launch:verify -- --domain CHOSEN_DOMAIN --strict
