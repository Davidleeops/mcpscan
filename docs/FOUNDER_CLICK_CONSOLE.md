## Launch Positioning

Sell MCPScan as a pre-enablement MCP readiness audit for teams turning on Copilot, Claude Code, Cursor, VS Code agent mode, Slack MCP, or Atlassian Rovo.

Primary promise:

```text
Enable MCP safely before developer-agent tool access becomes unmanaged.
```

Best first-customer wedge:

```text
Before you turn on MCP broadly, run a fixed-scope MCP Launch Audit:
discover configs, inventory servers, classify read/write/destructive tools,
detect risky auth/secrets, check allowlist drift, and produce an AppSec-ready
approval report.
```

Avoid leading with "AI governance platform" or "MCP gateway." Those markets are crowded and create the wrong comparison. Lead with independent readiness, evidence, and drift assessment across the tools buyers already use.

## Current Recommendation

Buy `getmcpscan.com` if it is available at normal pricing. It is the most credible primary domain for a security-audit buyer while keeping the MCPScan name.

Fallbacks: `trymcpscan.com`, then `mcpscanhq.com`, then `usemcpscan.com`.

Avoid using `.online` as the primary brand domain unless minimizing first-year cash spend is more important than buyer trust. Spaceship advertises very low first-year `.online` pricing, but the renewal is much higher and the extension looks less serious for an AppSec purchase.

## Remaining Founder Clicks

1. Buy the domain in Spaceship, then use `ops/domain-email-dns-console.html` for GitHub Pages and selected mail-provider DNS records.
2. Create `security@{{chosen_domain}}`, add `audit@` and `hello@` aliases, and copy the DKIM record the mail provider displays.
3. Create the three Stripe Payment Links using `ops/stripe-click-setup.html`.
4. Approve the generated command that applies those links to the landing page.
5. Approve exact first outbound messages in `ops/outbound-approval-console.html` before anything is sent.
6. Publish npm through `ops/npm-publish-console.html` only after npm login/package ownership is confirmed.
7. Deliver paid audits through `ops/delivery-console.html` and copy the workspace template outside the public repository.
