# MCPScan Market Source Pack

Date: August 14, 2026

Use this as the short approval pack before changing the offer, approving public posts, or choosing the first outbound channel.

## Reality Call

This is still a real opportunity, but the first sale should be a productized audit, not a generic scanner signup.

The market is moving toward MCP governance, server approval, tool permissions, token handling, tool poisoning, shadow MCP usage, and audit evidence. That favors a fast service offer where MCPScan produces proof and the buyer gets a defensible report.

## First Revenue Offer

Default offer:

- MCP Launch Audit at $1,500.
- Fixed scope, paid before intake.
- Best for AI agent teams, devtool startups, SaaS teams, and platform teams connecting agents to code, customer data, SaaS tools, cloud actions, or internal workflows.

Fallback offer:

- MCP Exposure Snapshot at $499 to $750.
- Use when the buyer is interested but not ready for the full audit.
- Keep scope tight: one environment, short risk inventory, no remediation call unless paid separately.

Do not lead with:

- "Scanner platform."
- "Full pentest."
- "Compliance certification."
- "Guaranteed secure."

Lead with:

- "MCP approval evidence."
- "Tool permission and credential review."
- "A buyer-safe report your team can use before enterprise review."

## Buyer Pain To Use

Use these questions in outbound and discovery:

- Which MCP servers are approved, and where are shadow servers still running?
- Which tools can read, write, delete, deploy, send, pay, or change production state?
- Are Cursor, Claude, ChatGPT, Copilot, VS Code, and local developer configs following the same approval rules?
- Can AppSec inspect tool descriptions, tool arguments, OAuth scopes, token handling, and environment variables before rollout?
- Can the team show audit evidence for SOC 2, ISO 27001, customer diligence, or internal AI governance?
- Is a gateway enough, or does the team still need pre-gateway inventory and remediation proof?

## Best First Buyers

Prioritize:

1. AI agent startups shipping MCP integrations.
2. Devtool companies with public MCP servers.
3. B2B SaaS teams adding Claude, ChatGPT, Cursor, Copilot, Codex, or custom agent workflows.
4. Automation agencies connecting agents to client systems.
5. AppSec leads asked to approve MCP without a mature checklist.
6. Platform security teams setting registries, allowlists, and managed connector rules.
7. Developer productivity leads rolling MCP into IDE and CLI workflows.
8. AI governance owners who need downstream data-control evidence.

Avoid first:

- Hobby MCP projects.
- Teams with no sensitive data, credentials, or production-like access.
- Buyers asking for formal certification or broad pentest scope.
- Enterprises already deep in a large AI security procurement unless they need a pre-procurement readiness audit.

## Domain And Mailbox Decision

Recommended cart order:

1. `getmcpscan.com`
2. `trymcpscan.com`
3. `mcpscanhq.com`
4. `usemcpscan.com`
5. `mcpscan.pro`
6. `getmcpscan.xyz`
7. `mcpscan.site`

Buy a `.com` if it is standard-priced. A 98 cent domain is acceptable only for speed validation, but it is weaker for security sales email and may have a renewal trap.

Mailbox:

- Create one paid mailbox at `security@chosen-domain`.
- Add aliases for `audit@chosen-domain` and `hello@chosen-domain` if included.
- Do not buy hosting, site builder, paid SSL, extra domains, or extra mailboxes for first revenue.
- Cheapest credible email path is Zoho Mail Lite. Use Google Workspace if mailbox trust matters more than cost. Use Spacemail if keeping domain and mailbox together inside Spaceship matters most.
